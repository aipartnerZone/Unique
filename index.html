तरीका 1: GitHub Releases से सीधा APK डाउनलोड करें (Recommended)
आपकी GitHub रिपॉजिटरी (aipartnerZone/Unique) पहले से जुड़ी हुई है। जब GitHub Actions बिल्ड पूरा हो जाए (हरा टिक ✅ दिखे), तो नीचे बटन दबाकर सीधा Munna-AI.apk डाउनलोड करें:
👉 डायरेक्ट डाउनलोड लिंक (Munna-AI.apk) ⚙️ GitHub बिल्ड स्टेटस देखें
तरीका 2: Google AI Studio से सीधा डाउनलोड करें
1. Google AI Studio में ऊपर दाएँ कोने (Top-Right) में Settings (⚙️) / Export पर टैप करें।
2. Generate APK पर क्लिक करें।
3. डाउनलोड हुई .apk फ़ाइल पर टैप करके अपने Android फ़ोन में Install कर लें!
